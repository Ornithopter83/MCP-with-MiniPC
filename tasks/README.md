# tasks 문서 사용 규칙

제1조 (문서 성격)

① `tasks/*.md`는 기능 도입 과정의 목표, 구현 단계, 검증 결과와 당시 판단을 보존하는 작업 기록이다.
② 작업 문서는 현재 장기 정책, 현재 역할 wire 계약 또는 현재 런타임 상태의 원본이 아니다.
③ 작업 문서 안의 `현재`, `활성`, `잔여`, 버전, commit, 경로와 복구 기준은 해당 문서가 작성·갱신된 시점의 사실로 해석한다.

제2조 (우선순위)

① 현재 의미가 충돌하면 `Master-Polish.md`, 프로젝트별 `*-Polish.md`, 전용 역할·API·전송 계약, 현재 구현·테스트의 순서로 확인한다.
② `CurrentWork.md`는 사용자가 현재 상태 확인을 요청했을 때 프로젝트별 표지판으로만 사용한다.
③ 과거 task의 규칙을 새 작업에 자동 재적용하지 않는다.

제3조 (과거 설계)

① HIGH 역할, 과거 직렬 runtime, 프로그램 재시작 후 session-state 자동 복구, RESOURCE 초기 wire처럼 현재 정책에서 제거·변경된 설계는 이력으로만 보존한다.
② 과거 작업 문서가 현재 정책과 다르면 과거 문서를 고쳐서 역사를 다시 쓰기보다 상단 상태 표시로 현재 원본이 아님을 명확히 한다.
